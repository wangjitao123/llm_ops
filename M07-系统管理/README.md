# M07 系统管理模块

## 模块概述

系统管理模块是大模型监测管理平台的基础支撑模块，提供统一的安全认证、消息通知、操作审计等核心基础设施能力。本模块确保系统的安全性、可追溯性和协同效率，是平台稳定运行的基石。

通过 SSO 统一认证实现单点登录和统一的身份管理；通过钉钉通知推送实现重要事件的实时告警；通过操作审计记录所有关键操作的完整轨迹，满足合规审计要求。

### 核心能力

- **统一认证体系**：支持 OAuth2、SAML、LDAP、CAS 等多种认证方式，统一管理用户身份和权限
- **实时通知推送**：集成钉钉机器人，支持事件驱动的消息推送、@指定成员、多环境配置
- **全量操作审计**：记录所有关键操作的用户、时间、IP、操作内容、结果等完整信息，支持查询和导出

## 功能点列表

### F-018 SSO 统一认证

| 功能编号 | 功能名称 | 优先级 | 说明 |
|---------|---------|-------|------|
| F-018-01 | SSO 登录跳转 | P0 | 用户访问系统时跳转到统一登录页完成认证 |
| F-018-02 | 多协议支持 | P0 | 支持 OAuth2、SAML、LDAP、CAS 四种认证协议 |
| F-018-03 | 回调与用户信息获取 | P0 | 认证通过后回调系统，获取用户信息 |
| F-018-04 | 本地会话创建 | P0 | 认证通过后在系统内创建本地会话 |
| F-018-05 | JWT Token 签发 | P0 | 签发访问令牌，用于后续 API 鉴权 |
| F-018-06 | Token 刷新 | P1 | 支持 Token 自动/手动刷新机制 |
| F-018-07 | 登出与会话销毁 | P0 | 用户登出时销毁本地会话和 Token |
| F-018-08 | 多协议配置管理 | P1 | 管理不同认证协议的接入配置（客户端 ID、密钥等） |

### F-019 钉钉通知推送

| 功能编号 | 功能名称 | 优先级 | 说明 |
|---------|---------|-------|------|
| F-019-01 | Webhook 配置管理 | P0 | 配置钉钉群机器人的 Webhook URL |
| F-019-02 | 通知事件配置 | P0 | 选择需要推送通知的系统事件类型 |
| F-019-03 | 消息模板管理 | P1 | 自定义通知消息的内容模板 |
| F-019-04 | @指定成员 | P1 | 在推送消息中 @指定团队成员 |
| F-019-05 | 测试推送 | P0 | 发送测试消息验证 Webhook 配置是否正常 |
| F-019-06 | 多环境配置 | P1 | 区分开发/测试/生产环境配置不同的 Webhook |
| F-019-07 | 推送记录查询 | P2 | 查看历史推送记录和送达状态 |

### F-020 操作日志审计

| 功能编号 | 功能名称 | 优先级 | 说明 |
|---------|---------|-------|------|
| F-020-01 | 操作日志记录 | P0 | 自动记录所有关键用户操作 |
| F-020-02 | 日志内容标准化 | P0 | 统一日志格式：操作人、时间、IP、操作类型、详情、结果 |
| F-020-03 | Key 操作监控 | P0 | 针对关键操作（模型变更、路由修改、系统配置变更）重点关注 |
| F-020-04 | 日志持久化存储 | P0 | 日志数据持久化，支持长期保存 |
| F-020-05 | 日志查询筛选 | P0 | 按时间、操作人、操作类型、IP 等多条件组合查询 |
| F-020-06 | 日志导出 | P1 | 支持导出为 Excel / CSV 格式 |
| F-020-07 | 日志详情查看 | P1 | 查看单条日志的完整上下文信息 |

### 审计日志记录范围

| 操作类别 | 具体操作 | 记录等级 |
|---------|---------|---------|
| **Key 操作** | 用户登录/登出、权限变更、角色分配 | ⭐ 高 |
| **模型变更** | 模型注册/删除、模型部署/下架、模型配置修改 | ⭐ 高 |
| **路由修改** | API 路由添加/修改/删除、负载均衡配置 | ⭐ 高 |
| **系统配置变更** | 系统参数修改、告警阈值变更、日志级别调整 | ⭐ 高 |
| **日常操作** | 数据查询、任务查看、报告导出 | 📋 中 |
| **只读操作** | 页面访问、列表浏览 | 🔹 低 |
