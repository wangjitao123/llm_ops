# M03 — Token 统计模块

> **模块编号：** M03  
> **模块名称：** Token 统计  
> **所属系统：** 大模型监测管理平台  
> **版本历史：** v1.0（初稿）

---

## 1. 模块概述

Token 统计模块是平台的核心数据能力模块，负责对**所有大模型 API 调用的 Token 消耗**进行全链路的实时采集、计算、存储、展示与预警。该模块支撑三大核心场景：

1. **用量统计** — 实时监控 Token 消耗趋势、调用分布，为运维和开发提供可视化仪表盘。
2. **费用报表** — 基于 Token 消耗数据与模型单价，自动核算费用，支持多维度查看与报表导出。
3. **用量预警** — 设置用量阈值，在达到预警线时自动通过钉钉等渠道推送通知，避免超预算风险。

**设计目标：**
- **实时性：** 页面数据刷新间隔 < 30 秒
- **准确性：** 费用计算严格基于已持久化的聚合数据
- **可追溯：** 支持按模型 / 应用 / 用户 / Key 逐层下钻
- **可预警：** 支持 80% 警告 / 100% 严重二级预警，防重复通知

| 项目 | 内容 |

| 项目 | 内容 |
|------|------|
| **功能编号** | F-009 |
| **功能名称** | 多维度费用报表 |

## 4. 角色与权限

| 角色 | 编码 | 所属子模块访问权限 | 说明 |
|------|------|-------------------|------|
| **平台管理员** | `admin` | M03-01 ✓ / M03-02 ✓ / M03-03 ✓ | 全部功能可见，可配置预警规则 |
| **应用开发者** | `developer` | M03-01 ✓ / M03-02 ✗ / M03-03 ✗ | 仅查看与自己相关应用的用量统计 |
| **业务管理者** | `manager` | M03-01 ✓ / M03-02 ✓ / M03-03 ✗ | 可查看用量与费用报表，不可配置预警 |

### 权限矩阵明细

| 功能点 | 平台管理员 | 应用开发者 | 业务管理者 |
|--------|-----------|-----------|-----------|
| F-008 用量实时统计 | ✅ 全量 | ✅ 本人应用 | ✅ 全量 |
| F-009 费用报表 | ✅ 查看+导出 | ❌ 无权限 | ✅ 查看+导出 |
| F-010 用量预警配置 | ✅ 配置 | ❌ 无权限 | ❌ 无权限 |

### 数据权限说明

- **应用开发者：** 系统自动过滤数据，仅展示该开发者名下或所属团队的 API Key 所对应的调用数据。
- **平台管理员 & 业务管理者：** 展示全平台聚合数据，不受应用级过滤。

## 5. 关键数据流概要

```
API 请求 → 网关日志 → MQ (Kafka/RocketMQ)
                              ↓
                        Redis 实时计数
                              ↓
                     MySQL 聚合表（分钟/小时/天）
                              ↓
                    ┌────┬────┬────┐
                    │用量 │费用 │预警│
                    └────┴────┴────┘
```

> 详细业务流程见各子模块的 `业务流程图.md`。
