# M05 模型微调模块

## 模块概述

模型微调模块是大模型监测管理平台的核心能力模块之一，提供从数据集管理、微调任务编排到结果评估的全链路支持。用户可以通过本模块对基座大模型进行高效、可控的微调训练，以满足特定业务场景下的模型定制需求。

本模块基于业界主流微调框架（如 LoRA、QLoRA、P-Tuning 等）进行了封装，降低了模型微调的技术门槛，同时保留了高级参数配置能力，兼顾易用性与灵活性。

### 核心能力

- **数据集全生命周期管理**：支持数据上传、格式转换、标注管理、版本控制
- **微调任务编排与调度**：支持任务创建、队列管理、训练监控、暂停/恢复/取消
- **自动化结果评估**：微调完成后自动评估，多维度对比微调前后指标
- **模型部署集成**：微调完成的模型可直接一键部署到推理服务

## 功能点列表

### F-014 微调任务管理

| 功能编号 | 功能名称 | 优先级 | 说明 |
|---------|---------|-------|------|
| F-014-01 | 创建微调任务 | P0 | 填写任务名称、选择基座模型、选择数据集、配置超参数 |
| F-014-02 | 基座模型选择 | P0 | 从已接入的模型列表中选择待微调的基座模型 |
| F-014-03 | 数据集关联 | P0 | 选择已预处理的数据集作为训练/验证数据 |
| F-014-04 | 超参数配置 | P0 | 配置学习率、Epoch、Batch Size、LoRA rank 等训练参数 |
| F-014-05 | 任务调度执行 | P0 | 提交任务到调度队列，按优先级和资源情况进行排队执行 |
| F-014-06 | 训练进度监控 | P0 | 实时查看训练进度、Loss 曲线、GPU 利用率等指标 |
| F-014-07 | 训练暂停/恢复 | P1 | 手动暂停运行中的任务，条件满足后恢复训练 |
| F-014-08 | 任务取消 | P0 | 取消排队中或运行中的任务，释放资源 |
| F-014-09 | 任务历史查看 | P1 | 查看已完成/失败的任务记录和训练日志 |
| F-014-10 | 微调模型部署 | P1 | 微调完成后一键部署模型到推理服务 |

### F-015 数据集管理

| 功能编号 | 功能名称 | 优先级 | 说明 |
|---------|---------|-------|------|
| F-015-01 | 数据集上传 | P0 | 支持上传 CSV、JSONL、Alpaca 格式的微调数据集 |
| F-015-02 | 数据格式转换 | P1 | 在不同数据格式之间进行自动转换 |
| F-015-03 | 数据预览 | P0 | 表格/卡片形式展示数据集内容，支持分页浏览 |
| F-015-04 | 数据统计 | P1 | 展示数据集样本量、Token 分布、标签分布等统计信息 |
| F-015-05 | 标注管理 | P1 | 支持人工标注工作流，状态流转管理 |
| F-015-06 | 版本管理 | P1 | 数据集版本控制，支持版本回溯和差异对比 |
| F-015-07 | 数据校验 | P0 | 自动检测数据格式异常、缺失字段等问题 |

### F-016 微调结果评估

| 功能编号 | 功能名称 | 优先级 | 说明 |
|---------|---------|-------|------|
| F-016-01 | 自动评估 | P0 | 微调完成后自动触发评估流程 |
| F-016-02 | 指标计算 | P0 | 计算 Accuracy、BLEU、ROUGE-L、推理延迟等指标 |
| F-016-03 | 微调前后对比 | P0 | 对比微调前后模型在测试集上的各项指标变化 |

| F-016-06 | 评估历史 | P2 | 查看历史评估记录，支持多次评估结果对比 |
