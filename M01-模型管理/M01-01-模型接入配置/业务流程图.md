# M01-01 模型接入配置 — 业务流程图

## 所属模块

- **模块编号**：M01-01
- **模块名称**：模型接入配置
- **对应功能**：F-002 模型接入与配置
- **关联功能点**：F-002.1 模型列表、F-002.2 模型配置表单、F-002.3 模型连通性测试、F-002.4 模型启停控制

- **前置条件**：管理员已通过 SSO 认证登录平台

## 流程说明

### 1. 接入新模型流程（主流程）

| 步骤 | 操作 | 角色 | 说明 |
|------|------|------|------|
| 1 | 管理员进入模型管理页面 | 平台管理员 | 系统展示已接入模型列表 |
| 2 | 点击"添加模型"按钮 | 平台管理员 | 弹出模型配置表单 |
| 3 | 选择模型厂商模板 | 平台管理员 | 系统预设 DeepSeek、GPT、通义千问、文心一言、Claude、Gemini 等模板，自动填充常见参数 |
| 4 | 填写配置信息 | 平台管理员 | 填写模型名称、API 地址、API Key、QPS 上限、超时时间、权重等 |
| 5 | 连通性测试 | 系统自动 | 保存前向 API 地址发送请求验证可达性 |
| 6 | 保存配置 | 平台管理员 | 校验通过后保存，模型出现在列表中，初始状态为"待配置" |

### 2. 编辑模型流程

| 步骤 | 操作 | 角色 | 说明 |
|------|------|------|------|
| 1 | 找到目标模型 | 平台管理员 | 可通过搜索或筛选快速定位 |
| 2 | 修改配置 | 平台管理员 | 修改任意配置参数 |
| 3 | 保存生效 | 系统自动 | 新配置立即生效，无需重启 |

### 3. 启停控制流程

| 操作 | 前置状态 | 后置状态 | 网关行为 |
|------|---------|---------|---------|
| 停用 | 在线 | 离线 | 停止路由请求到该模型 |
| 启用 | 离线 | 在线 | 恢复路由请求到该模型 |

### 4. 删除模型流程

| 步骤 | 操作 | 角色 | 说明 |
|------|------|------|------|
| 1 | 确认删除 | 平台管理员 | 二次确认，防止误操作 |
| 2 | 删除数据 | 系统自动 | 从数据库物理删除，不可恢复 |

## 界面元素

| 界面元素 | 类型 | 说明 |
|---------|------|------|
| 模型列表 | 表格 | 展示模型名称、厂商、状态、响应时间、QPS、操作按钮 |
| 添加模型按钮 | 按钮 | 触发添加模型流程 |
| 配置表单 | 对话框/页面 | 包含模型名称、API 地址、API Key、QPS、超时、权重等字段 |
| 连通性测试按钮 | 按钮 | 测试 API 可达性 |
| 启停开关 | 切换按钮 | 控制模型的启用/停用状态 |
| 编辑按钮 | 按钮 | 编辑模型配置 |
| 删除按钮 | 按钮 | 删除模型 |

---

## 异常处理

| 异常场景 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 配置的 API 地址不可达 | 连通性测试失败，阻止保存 | "模型 API 不可达，请检查地址" |
| QPS 配置超过默认上限 | 保存时弹出警告 | "建议 QPS 不超过 500" |
| 停用模型时该模型正在处理请求 | 等待当前请求处理完毕后再停用 | "模型正在处理请求，请稍后再试" |
| 删除模型时该模型关联了路由规则 | 提示先删除关联路由规则 | "该模型已被路由规则引用，请先删除关联规则" |
