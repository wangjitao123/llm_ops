# M02 — Key 管理模块

> **模块编号：** M02  
> **模块名称：** Key 管理  
> **所属系统：** 大模型监测管理平台  
> **版本历史：** v1.0（初稿）

---

## 1. 模块概述

Key 管理模块是平台的安全与鉴权基础模块，负责企业内所有 API Key 的全生命周期管理。该模块支撑三大核心场景：

1. **Key 生成与分发** — 管理员为应用开发者生成访问密钥，支持配置可调用模型、速率限制、过期时间等，生成后仅展示一次完整 Key，后续仅显示脱敏格式。
2. **Key 权限与速率控制** — 精细控制每个 Key 的模型访问权限和调用速率，支持「全局默认 + 单 Key 自定义」两级策略体系。
3. **Key 生命周期管理** — 管理 Key 从创建到回收的完整生命周期，支持手动启用/禁用、自动过期禁用、到期提醒和回收后数据保留。

### 设计目标

- **安全性**：完整 Key 仅生成时刻展示一次，后续全平台脱敏；支持即时禁用
- **精细化**：两级速率策略（全局默认 + 单 Key 自定义），QPS/RPM/RPD/Token 上限四级控制
- **自动化**：到期前 7 天自动提醒，过期自动禁用，回收后数据保留 90 天可追溯

## 3. 功能点列表

### F-005 — API Key 生成与分发（Must | RICE 评分 9.5）

**功能描述**：支持管理员生成和分发 API Key，应用开发者获取密钥后接入 AI 统一网关。

| 功能点编号 | 功能点名称 | 描述 | 优先级 | 复杂度 |
|-----------|-----------|------|--------|--------|
| F-005 | API Key 生成与分发 | 生成、分发 API Key，支持权限配置 | Must | M |
| F-005.1 | Key 列表 | 展示所有 Key，支持搜索和状态筛选 | Must | S |
| F-005.2 | Key 生成表单 | 配置名称、应用、可调用模型、速率限制、Token 上限、过期时间 | Must | M |
| F-005.3 | Key 脱敏显示 | 生成后仅展示一次完整 Key，后续显示为脱敏格式 | Must | S |

**业务规则**：
- Key 前缀固定为 `sk-`，后接 40 位随机字符（共 43 位）
- 完整 Key 仅在生成成功后弹出展示一次，页面刷新后不再可获取
- 列表页及详情页统一展示为脱敏格式：`sk-****....****{后4位}`
- 支持复制脱敏 Key（用于日志记录），完整 Key 需管理员重新生成
- 生成时可关联所属应用，用于后续费用分摊

**异常处理**：
| 异常场景 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 表单必填项缺失 | 前端校验后拒绝提交 | 标红必填字段并提示 |
| Key 生成失败（系统异常） | 事务回滚，记录错误日志 | "Key 生成失败，请稍后重试" |
| 开发者关闭弹窗未复制 Key | 提供「重新生成」入口（旧 Key 自动失效） | "请务必保存完整 Key，关闭后不可恢复" |

---

### F-006 — Key 权限与速率控制（Must | RICE 评分 9.0）

**功能描述**：控制每个 Key 的模型访问权限和调用速率，提供两级速率策略体系。

| 功能点编号 | 功能点名称 | 描述 | 优先级 | 复杂度 |
|-----------|-----------|------|--------|--------|
| F-006 | Key 权限与速率控制 | 控制 Key 的模型访问权限和调用速率 | Must | M |

**业务规则**：
- 两级速率策略体系：
  - **全局默认**：系统级别的默认速率限制，适用于所有未自定义的 Key
  - **单 Key 自定义**：针对特定 Key 单独设置，覆盖全局默认值
- 速率控制维度：QPS（每秒请求数）、RPM（每分钟请求数）、RPD（每天请求数）
- Token 上限：单个 Key 在指定周期内最大 Token 消耗量
- 模型访问权限：允许指定 Key 可调用的模型列表（白名单机制）
- 默认策略：新 Key 继承全局默认速率，无模型访问限制（即所有已启用的模型均可调用）

**异常处理**：
| 异常场景 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 单 Key QPS 超过全局默认值 | 保存时弹出确认弹窗 | "自定义 QPS 超过全局默认值，是否确认？" |
| 速率配置格式错误 | 前端校验后拒绝提交 | "请输入正整数" |
| 模型已停用但仍被选中 | 保存时自动移除并提示 | "模型「xxx」已停用，已自动移除" |

---

### F-007 — Key 生命周期管理（Should | RICE 评分 7.0）

**功能描述**：管理 Key 从创建到回收的完整生命周期，包括启用、禁用、过期、回收等状态转换。

| 功能点编号 | 功能点名称 | 描述 | 优先级 | 复杂度 |
|-----------|-----------|------|--------|--------|
| F-007 | Key 生命周期管理 | Key 的启用/禁用/回收，到期自动禁用 | Should | M |

**业务规则**：
- 状态定义：`启用` → `使用中`（已有调用记录）→ `禁用`（手动）/ `过期`（自动）→ `回收`（删除）
- 到期前 7 天自动发送提醒通知（钉钉/站内信）
- Key 过期后自动切换为「过期」状态，不再接受鉴权请求
- 过期 Key 的完整使用记录持续保留 90 天，90 天后可被系统自动回收
- 回收操作仅为逻辑标记删除，关联的请求日志仍保留（数据不物理删除）
- 已禁用的 Key 可手动重新启用，重新启用后继承原有配置

**异常处理**：
| 异常场景 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 管理员禁用正在被使用的 Key | 弹出二次确认弹窗 | "该 Key 当前正在被使用，禁用后将立即中断所有请求，是否确认？" |
| 回收操作（90 天后自动清理） | 系统定时任务执行，记录操作日志 | — |
| 重新启用已过期的 Key | 需同时延长过期时间 | "该 Key 已过期，请先设置新的过期时间" |

## 4. 角色与权限

| 角色 | 编码 | 所属子模块访问权限 | 说明 |
|------|------|-------------------|------|
| **平台管理员** | `admin` | M02-01 ✓ / M02-02 ✓ / M02-03 ✓ | 全部功能可见，可生成/编辑/禁用/回收所有 Key |
| **应用开发者** | `developer` | M02-01 ✓(仅查看本人Key) / M02-02 ✗ / M02-03 ✗ | 仅查看与自己相关的 Key 列表和脱敏信息，不可修改 |

### 权限矩阵明细

| 功能点 | 平台管理员 | 应用开发者 |
|--------|-----------|-----------|
| F-005.1 查看 Key 列表 | ✅ 全量 | ✅ 本人 Key |
| F-005.2 生成新 Key | ✅ | ❌ |
| F-005.3 查看完整 Key（生成时刻） | ✅ | ✅（仅本人 Key） |
| F-006 Key 权限与速率配置 | ✅ | ❌ |
| F-007 启用/禁用 Key | ✅ | ❌ |
| F-007 回收 Key | ✅ | ❌ |
| F-007 延长过期时间 | ✅ | ❌ |

### 数据权限说明

- **应用开发者**：系统自动过滤数据，仅展示该开发者名下或所属团队的 API Key。
- **平台管理员**：展示全平台所有 API Key，不受应用级过滤。

## 5. 模块依赖关系

| 依赖方向 | 模块 | 依赖说明 |
|---------|------|---------|
| **依赖** | M01 模型管理 | Key 的模型访问权限需要引用已接入的模型列表 |
| **被依赖** | M04 统一网关 | 网关的请求鉴权需要校验 API Key 的有效性和速率限制 |
| **被依赖** | M03 Token 统计 | Token 统计需要按 Key 维度聚合用量和费用 |
| **依赖** | M07 系统管理 | 依赖 SSO 认证模块进行用户身份和角色识别 |

## 6. 数据实体概要

| 实体 | 说明 | 关键字段 |
|------|------|---------|
| ApiKey | API Key 实例 | id, key_hash(name), display_name(prefix+suffix), app_name, status, permissions, rate_limit_config, token_quota, expired_at, created_by, created_at |
| RateLimitConfig | 速率限制配置 | id, key_id(可为null), qps, rpm, rpd, token_limit, is_global_default |
| KeyPermission | Key 模型权限 | id, key_id, model_id, granted |
| KeyAuditLog | Key 操作审计日志 | id, key_id, action, operator, detail, created_at |
