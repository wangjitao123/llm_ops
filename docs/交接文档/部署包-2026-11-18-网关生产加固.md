**包名**：`gateway_prod_hardening.zip`
**内容**：三项改动 —— ① nginx 流式转发参数 ② 非流式请求提前归还数据库连接 ③ 生产参数清单 + Postgres 连接数上限

**形式**：整文件覆盖（沿用历史补丁包约定），解压到项目根目录即可

## 3. 部署顺序

> 代码先上、Postgres 后重启：这样 Postgres 短暂断连期间，新代码已经就绪。

```bash
cd /data/llm_ops/deploy

# ---- 第一步：代码类改动（① ②）----

docker compose up -d api-server web

# ---- 第二步：Postgres 连接数（③，会重启 postgres，数据在卷里不丢）----
docker compose up -d postgres
```

## 6. 行为变化说明（可能会被问到）

| 变化 | 影响 |
|------|------|
| 非流式请求不再全程持有 DB 连接 | 并发上限从 `(20+30)×workers` 提升到不再受连接池约束；每请求多一次池取连接（约 0.1–1ms），相对秒级生成可忽略 |
| `ENABLE_DEV_LOGIN` 默认仍是 `true` | **刻意不改**：前端登录页目前只走 dev-login，改 false 会导致全员无法登录。接入 SSO 后再改（详见 `deploy/生产环境参数清单.md` §0） |
| Postgres 重启 | `up -d postgres` 会重建容器，几秒断连；数据在 `postgres_data` 卷里 |
| `PERF_TESTABLE_PROVIDER_PREFIX` 现在真能生效 | 默认留空 = 不限制，与现状一致 |
