# M07 系统管理模块

## 模块概述

系统管理模块提供平台的基础设施能力，包括 SSO 统一认证、钉钉通知推送和操作日志审计，为平台的安全运行和可观测性提供保障。

## 子模块清单

| 子模块编号 | 子模块名称 | 优先级 | 功能点 |
|------------|-----------|--------|--------|
| M07-01 | SSO 认证 | Must | F-018 SSO 统一认证 |
| M07-02 | 通知推送 | Could | F-019 钉钉通知推送 |
| M07-03 | 操作审计 | Should | F-020 操作日志审计 |

## 功能点列表

| 功能编号 | 功能名称 | 优先级 | 复杂度 |
|----------|----------|--------|--------|
| F-018 | SSO 统一认证 | Must | M |
| F-019 | 钉钉通知推送 | Could | M |
| F-020 | 操作日志审计 | Should | M |

## 角色与权限

| 角色 | 权限 |
|------|------|
| 平台管理员 | 全部操作：配置 SSO、通知、查看审计日志 |
| 所有用户 | 通过 SSO 登录系统 |
