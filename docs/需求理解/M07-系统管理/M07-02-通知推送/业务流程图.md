# M07-02 通知推送 — 业务流程图

## 流程概述

管理员配置钉钉机器人 Webhook URL，选择通知事件类型，系统在触发事件时自动构建消息并推送到钉钉群。

## 业务流程图

```mermaid
flowchart TD
    %% 配置阶段
    START([开始]) --> CONFIG[进入通知配置页面]
    CONFIG --> C1[填写钉钉机器人 Webhook URL]
    C1 --> C2[配置加签密钥<br/>可选]
    C2 --> C3[@指定手机号<br/>可选]
    C3 --> C4[选择通知事件]
    
    C4 --> E1[Token 用量预警]
    C4 --> E2[模型异常告警]
    C4 --> E3[微调任务完成/失败]
    C4 --> E4[Key 过期提醒]
    
    E1 --> C5[保存配置]
    C5 --> TEST{是否测试?}
    TEST -->|是| TEST_SEND[发送测试消息]
    TEST_SEND --> TEST_RESULT{测试结果}
    TEST_RESULT -->|成功| TEST_OK[提示"推送成功"]
    TEST_RESULT -->|失败| TEST_FAIL[提示"推送失败<br/>请检查 Webhook URL"]
    TEST_FAIL --> C1
    TEST_OK --> DONE[配置完成]
    TEST -->|否| DONE
    
    %% 触发阶段
    DONE --> TRIGGER[等待事件触发]
    TRIGGER --> EVENT{事件类型}
    
    EVENT -->|Token 预警| ALERT[预警事件]
    EVENT -->|模型异常| ALERT
    EVENT -->|微调完成| FT_DONE[微调事件]
    EVENT -->|Key 过期| KEY_EXP[Key 事件]
    
    ALERT --> BUILD[构建告警消息]
    FT_DONE --> BUILD
    KEY_EXP --> BUILD
    
    BUILD --> MSG[Markdown 格式消息]
    MSG --> TITLE[标题: 🚨 事件类型]
    MSG --> BODY[正文: 详情描述]
    MSG --> TIME[时间: 发生时间]
    MSG --> ADVICE[建议: 处理建议]
    
    TITLE --> PUSH[发送到钉钉机器人]
    PUSH --> PUSH_RESULT{发送结果}
    PUSH_RESULT -->|成功| LOG[记录通知日志]
    PUSH_RESULT -->|失败| RETRY[重试 3 次]
    RETRY -->|重试成功| LOG
    RETRY -->|重试失败| FAIL_LOG[记录失败日志]
    LOG --> TRIGGER
    FAIL_LOG --> TRIGGER
```

## 通知事件

| 事件 | 触发条件 | 严重级别 | 消息示例 |
|------|----------|----------|----------|
| Token 用量预警 | 用量达到阈值 80%/100% | ⚠️/🔴 | 今日 Token 用量已达 800,000 (80%) |
| 模型异常 | 模型离线/严重延迟 | 🔴 | DeepSeek-V3 已于 14:30 离线 |
| 微调完成 | 微调任务完成/失败 | ✅/❌ | 客服对话优化 微调已完成 |
| Key 过期 | Key 即将在 7 天后过期 | ⚠️ | 智能客服 Key 将于 2025-01-07 过期 |
