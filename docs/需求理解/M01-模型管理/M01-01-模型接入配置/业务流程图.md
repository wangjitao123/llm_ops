# M01-01 模型接入配置 — 业务流程图

## 流程概述

管理员通过管理控制台接入新模型，填写配置信息并进行连通性测试，保存后模型出现在列表中，支持启停控制。

## 业务流程图

```mermaid
flowchart TD
    START([开始]) --> A[管理员登录控制台]
    A --> B[进入模型管理页面]
    B --> C{选择操作}
    
    C -->|接入新模型| D[点击"接入模型"按钮]
    D --> E[填写配置信息]
    E --> E1[模型名称]
    E --> E2[API 地址]
    E --> E3[API Key]
    E --> E4[QPS 上限]
    E --> E5[超时时间]
    E --> E6[模型权重]
    E --> F[选择预设模板或自定义]
    F --> G[连通性测试]
    G --> G1{测试结果}
    G1 -->|成功| H[保存配置]
    G1 -->|失败| G2[提示"API 不可达"]
    G2 --> E
    H --> I[模型出现在列表中]
    I --> I1{状态判定}
    I1 -->|测试通过| I2[状态: 在线]
    I1 -->|未测试| I3[状态: 待配置]
    
    C -->|编辑模型| J[选择已有模型]
    J --> K[修改配置信息]
    K --> L[保存更新]
    L --> M[新配置立即生效]
    
    C -->|启停控制| N[选择模型]
    N --> O{当前状态}
    O -->|在线| P[点击停用]
    P --> Q[状态变为离线]
    Q --> R[网关停止路由到该模型]
    O -->|离线| S[点击启用]
    S --> T[状态变为在线]
    T --> U[网关恢复路由到该模型]
    
    I2 --> END([结束])
    I3 --> END
    M --> END
    R --> END
    U --> END
```

## 流程节点说明

| 节点 | 说明 | 角色 | 系统交互 |
|------|------|------|----------|
| 接入新模型 | 填写模型名称、API 地址、API Key 等配置 | 平台管理员 | 前端表单 |
| 连通性测试 | 保存时自动检测 API 地址是否可达 | 系统自动 | 发送 HTTP 请求到目标 API |
| 启停控制 | 启用/停用模型，控制网关路由 | 平台管理员 | 更新模型状态，通知网关 |

## 异常处理

| 异常场景 | 处理方式 | 用户提示 |
|----------|----------|----------|
| API 地址不可达 | 保存时提示，不阻塞保存 | "模型 API 不可达，请检查地址" |
| QPS 配置超限 | 保存时提示建议值 | "建议 QPS 不超过 500" |
| API Key 无效 | 保存时检测，仅提示不阻塞 | "API Key 验证失败，请确认" |
