# M01 模型管理模块

## 模块概述

模型管理模块负责企业内所有大模型的统一接入、配置、状态监控和版本管理。支持接入 DeepSeek、GPT、通义千问、文心一言、Claude、Gemini 等多种模型，提供统一的配置界面和运行状态看板。

## 子模块清单

| M01-02 | 模型状态监控 | Must | F-003 模型状态监控 |
| M01-03 | 模型版本管理 | Should | F-004 模型版本管理 |
