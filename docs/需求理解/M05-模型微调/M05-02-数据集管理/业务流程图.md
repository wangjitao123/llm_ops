# M05-02 数据集管理 — 业务流程图

## 流程概述

数据科学家上传训练数据集，支持多种格式，系统自动解析和预览数据内容，支持标注状态管理和版本管理。

## 业务流程图

```mermaid
flowchart TD
    %% 上传流程
    START([开始]) --> A[进入数据集管理页面]
    A --> B[点击"上传数据集"]
    B --> C[填写数据集信息]
    C --> C1[数据集名称]
    C --> C2[选择数据格式]
    C2 --> C2A[JSONL]
    C2 --> C2B[CSV]
    C2 --> C2C[JSON]
    C2 --> C2D[Parquet]
    C --> D[选择文件上传]
    D --> D1[拖拽或点击选择]
    D1 --> D2{文件校验}
    D2 -->|格式不支持| D3[提示格式错误]
    D2 -->|超过500MB| D4[提示文件过大]
    D2 -->|通过| D5[上传到服务器]
    D5 --> D6[数据预览]
    D6 --> D6A[显示样本数据]
    D6 --> D6B[显示样本总数]
    D6 --> D7[确认上传]
    D7 --> SAVE[保存数据集]
    SAVE --> V1[版本: v1.0]
    V1 --> LIST[数据集列表更新]
    
    %% 标注流程
    LIST --> ANNOTATE{选择操作}
    ANNOTATE -->|标注管理| AN_START[进入标注页面]
    AN_START --> AN_STATUS{当前标注状态}
    AN_STATUS -->|待标注| AN_LABEL[开始标注]
    AN_STATUS -->|标注中| AN_CONTINUE[继续标注]
    AN_STATUS -->|已标注| AN_REVIEW[提交审核]
    AN_STATUS -->|待审核| AN_APPROVE[审核通过/驳回]
    
    AN_LABEL --> AN_PROGRESS[标注进度: x%]
    AN_PROGRESS --> AN_DONE[标注完成]
    AN_DONE --> AN_REVIEW
    
    AN_REVIEW --> AN_PASS[审核通过]
    AN_PASS --> AN_COMPLETE[状态: 已审核]
    
    AN_APPROVE -->|驳回| AN_REJECT[退回标注中]
    AN_APPROVE -->|通过| AN_COMPLETE
    
    %% 版本管理
    ANNOTATE -->|版本管理| VER_LIST[查看版本列表]
    VER_LIST --> VER_ADD[创建新版本]
    VER_ADD --> VER_NOTE[填写版本说明]
    VER_ADD --> VER_SAVE[版本: v1.1/v2.0]
    VER_LIST --> VER_ROLLBACK[回滚到历史版本]
    VER_ROLLBACK --> VER_CONFIRM[确认回滚]
    VER_CONFIRM --> VER_DONE[版本已切换]
    
    AN_COMPLETE --> END([结束])
    LIST --> END
    VER_DONE --> END
```

## 数据格式说明

| 格式 | 文件扩展名 | 说明 | 典型用途 |
|------|-----------|------|----------|
| JSONL | `.jsonl` | 每行一个 JSON 对象 | 对话数据（消息序列） |
| CSV | `.csv` | 逗号分隔的表格数据 | 分类/标注数据 |
| JSON | `.json` | 标准 JSON 数组 | 结构化数据 |
| Parquet | `.parquet` | 列式存储格式 | 大规模数据集 |

## 标注状态流转

```
待标注 → 标注中 → 已标注 → 待审核 → 已审核
                                    → 驳回 → 标注中
```
