# M02 Key 管理模块

## 模块概述

Key 管理模块负责 API Key 的完整生命周期管理，包括生成、分发、权限控制、速率限制和回收。为企业内各应用提供安全、可控的 AI 模型调用凭证。

## 子模块清单

| 子模块编号 | 子模块名称 | 优先级 | 功能点 |
|------------|-----------|--------|--------|
| M02-01 | Key 生成分发 | Must | F-005 API Key 生成与分发 |
| M02-02 | Key 权限控制 | Must | F-006 Key 权限与速率控制 |
| M02-03 | Key 生命周期 | Should | F-007 Key 生命周期管理 |

## 功能点列表

| 功能编号 | 功能名称 | 优先级 | 复杂度 |
|----------|----------|--------|--------|
| F-005 | API Key 生成与分发 | Must | M |
| F-005.1 | Key 列表 | Must | S |
| F-005.2 | Key 生成表单 | Must | M |
| F-005.3 | Key 脱敏显示 | Must | S |
| F-006 | Key 权限与速率控制 | Must | M |
| F-007 | Key 生命周期管理 | Should | M |

## 角色与权限

| 角色 | 权限 |
|------|------|
| 平台管理员 | 全部操作：生成、配置、禁用、回收 |
| 应用开发者 | 查看自己的 Key、申请新 Key |
