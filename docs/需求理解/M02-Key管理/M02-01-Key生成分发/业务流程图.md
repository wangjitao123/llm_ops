# M02-01 Key 生成分发 — 业务流程图

## 流程概述

管理员或应用开发者通过管理控制台生成 API Key，配置关联应用、可调用模型、速率限制和过期时间，生成后仅展示一次完整 Key 值。

## 业务流程图

```mermaid
flowchart TD
    START([开始]) --> A[进入 Key 管理页面]
    A --> B[点击"生成 Key"按钮]
    B --> C[填写 Key 配置信息]
    C --> C1[Key 名称]
    C --> C2[关联应用]
    C --> C3[选择可调用模型列表]
    C --> C4[设置速率限制]
    C --> C5[设置 Token 上限]
    C --> C6[设置过期时间]
    C --> D[点击"立即生成"]
    
    D --> E[系统生成 API Key]
    E --> E1[规则: sk- + 随机字符串]
    E1 --> F[展示完整 Key]
    F --> F1[弹窗提示: "请立即保存，将不再展示"]
    F1 --> G{用户已保存?}
    G -->|是| H[关闭弹窗]
    G -->|否| F1
    H --> I[Key 列表显示脱敏格式]
    I --> I1[示例: sk-8a3f...b1e2]
    I --> J[Key 状态: 启用]
    
    J --> K[Key 列表展示]
    K --> K1[搜索/筛选]
    K --> K2[查看状态/速率/用量/过期时间]
    K --> K3[操作: 编辑/禁用/回收]
    
    K --> END([结束])
```

## 脱敏规则

| 阶段 | 展示格式 | 示例 |
|------|----------|------|
| 生成时（仅一次） | 完整 Key | `sk-8a3f7d2e1b4c5f9a0e8d7c6b5a4f3e2d1c` |
| 生成后 | 前缀 + 脱敏 | `sk-8a3f...b1e2` |
| 日志记录 | 仅前缀 | `sk-8a3f` |
