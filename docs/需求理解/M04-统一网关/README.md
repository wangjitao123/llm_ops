## 1. 模块概述

### 1.1 定位与职责

**统一网关**是整个大模型监测管理平台的 **流量入口与策略执行层**，位于客户端与后端模型服务之间。所有对模型的外部 API 调用均需经过统一网关，由网关完成 **身份认证、权限校验、速率限制、智能路由** 等职责后再转发到目标模型服务，并将调用结果和日志汇总上报。

统一网关屏蔽了不同模型厂商的 API 差异，对外暴露统一的 OpenAI 兼容接口（`/v1/chat/completions` 等），对内支持按路由策略分发到 DeepSeek、GPT、通义千问、文心一言等多种模型。

### 1.2 核心价值

| 价值维度 | 说明 |
|----------|------|
| **统一入口** | 所有模型调用经过一个端点，API 地址和鉴权方式统一 |
| **安全防护** | 集中鉴权 + 限流，防止 Key 滥用和恶意攻击 |
| **流量治理** | 支持加权轮询、主备切换、单点三种路由策略，实现负载均衡和高可用 |
| **可观测性** | 完整请求日志，支撑审计、排障和费用分摊 |
| **协议适配** | 统一的请求/响应格式转换，应用无需关注各厂商协议差异 |

### 3.2 F-011：统一 API 路由

**功能描述**：作为统一入口，根据路由规则分发请求到不同后端模型服务。

**业务规则**：

| 规则项 | 内容 |
|--------|------|
| 路由策略 | 加权轮询（Weighted Round-Robin）、主备切换（Active-Standby）、单点（Single） |
| 路由匹配 | 基于请求路径（如 `/v1/chat/completions`）和可选 Headers |
| 协议转换 | 统一请求格式 → 各厂商 API 格式；各厂商响应 → 统一格式 |
| 异常处理 | 目标模型不可用时自动切换（主备模式）；全部不可用返回 503 |

**接口示例**：

```
POST /v1/chat/completions
Authorization: Bearer sk-xxxxxxxxxxxx
Content-Type: application/json

{
  "model": "deepseek-chat",
  "messages": [{"role": "user", "content": "Hello"}]
}
```

### 3.3 F-012：请求鉴权与限流

**功能描述**：对每个 API 请求进行鉴权和速率限制。

**业务规则**：

| 规则项 | 内容 |
|--------|------|
| 鉴权流程 | 提取请求头 API Key → 校验 Key 有效性 → 校验模型访问权限 → 速率限制检查 |
| 全局限流 | 全局 Token Bucket，全局 QPS 上限可配置 |
| 单 Key 限流 | 每个 Key 独立 Token Bucket，单 Key QPS 上限可配置 |
| 鉴权失败 | 不计数（不计入限流统计） |
| 异常响应 | 401（无效 Key）、403（无权限）、429（限流，含 Retry-After 头） |

### 3.4 F-013：请求日志与审计

**功能描述**：记录所有 API 请求的完整日志，支持查询、审计和导出。

**业务规则**：

| 规则项 | 内容 |
|--------|------|
| 日志字段 | 请求时间、请求 ID、API Key 名称、应用、模型、请求路径、输入 Token 数、输出 Token 数、响应时间、状态码、来源 IP |
| 存储策略 | 活跃数据 30 天（InnoDB 快速查询），归档数据 180 天（可导出查询） |
| 写入方式 | 异步 MQ + 批量写入 MySQL，确保不丢不重 |
| 查询筛选 | 支持按时间范围、状态码、应用、模型筛选 |
| 导出格式 | CSV |

## 4. 角色与权限

### 4.1 相关角色

| 角色 | 说明 | 与本模块的关系 |
|------|------|---------------|
| **平台管理员** | 运维/系统管理员，负责系统配置和运维 | 管理路由规则、查看日志、配置限流参数 |
| **应用开发者** | 后端/算法工程师，调用模型 API | 通过网关调用模型（无需登录网关管理界面） |
| **业务管理者** | 技术经理/部门负责人 | 查看请求日志和用量报表（只读） |

### 4.2 权限矩阵

| 功能/操作 | 平台管理员 | 应用开发者 | 业务管理者 |
|-----------|-----------|-----------|-----------|
| 查看路由规则列表 | ✅ | ❌ | ❌ |
| 创建/编辑/删除路由规则 | ✅ | ❌ | ❌ |
| 启用/停用路由规则 | ✅ | ❌ | ❌ |
| 查看请求日志 | ✅ | ❌ | ✅（只读） |
| 导出请求日志 CSV | ✅ | ❌ | ✅ |
| 配置限流参数 | ✅ | ❌ | ❌ |
| 通过网关调用模型 API | ❌（非调用方） | ✅ | ❌ |

### 4.3 权限说明

- **网关管理界面**仅对平台管理员开放，用于配置路由规则和限流参数。
- **应用开发者**不直接管理网关，而是通过申请 API Key（F-005）后调用统一的网关 API。
- 鉴权与限流为系统自动执行，无需人工干预。
- 日志查询对业务管理者以只读方式开放，用于费用审计和用量分析。

## 5. 关键设计决策（ADR）

| 决策编号 | 决策项 | 选择方案 | 备选方案 | 理由 |
|----------|--------|----------|----------|------|
| ADR-004-01 | 路由策略实现 | 网关层 Service 实现 | 配置中心下发 | 策略粒度按路由规则配置，灵活度高 |
| ADR-004-02 | 限流算法 | Token Bucket | 漏桶算法 | 支持突发流量，更适合大模型调用场景 |
| ADR-004-03 | 日志写入 | 异步 MQ + 批量写入 | 同步直接写入 | 不影响主请求链路性能 |
| ADR-004-04 | 协议转换 | 适配器模式（Adapter） | 硬编码转换 | 新增厂商只需新增适配器，扩展性好 |
