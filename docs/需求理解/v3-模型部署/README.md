# 模型部署模块 — 需求理解文档

## 概述
| 项目 | 内容 |
|------|------|
| 所属项目 | 大模型监测管理平台 |
| 模块说明 | 支持将量化模型/HF模型一键部署为推理端点，同时支持注册已有 conda/Docker 端点，统一管理配置和监控 |
| 功能点总数 | 43（Must: 24, Should: 14, Could: 5） |
| 对应原型 | `docs/需求分析/v3-模型部署/prototype-v2/index.html` |

## 模块划分

| 编号 | 模块名称 | 对应功能点 | 复杂度 |
|------|----------|-----------|--------|
| M01 | 端点注册管理 | DPL-002, DPL-002.1, DPL-002.2 | H |
| M02 | 自动部署管理 | DPL-003, DPL-003.1-3.5, DPL-007, DPL-007.1-7.3, DPL-014 | H |
| M03 | 配置管理 | DPL-004~006, DPL-012, DPL-013 | M |
| M04 | 健康监控 | DPL-001, DPL-008~010 | M |
| M05 | 集成对接 | DPL-001.1-1.4, DPL-011 | M |

## 角色与权限

| 角色 | 可操作模块 | 说明 |
|------|-----------|------|
| 平台管理员 | M01~M05 | 完整管理权限 |
| AI 工程师 | M01, M03 | 注册自己的模型，配置工具 |
| 运维人员 | M04 | 监控和诊断 |
