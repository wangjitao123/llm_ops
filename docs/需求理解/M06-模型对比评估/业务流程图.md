# M06 模型对比评估 — 业务流程图

## 流程概述

管理员选择两个或多个模型，从多维度进行对比评估，系统加权计算综合评分，并根据场景给出推荐建议。

## 业务流程图

```mermaid
flowchart TD
    START([开始]) --> A[进入模型对比评估页面]
    A --> B[选择要对比的模型]
    B --> B1[选择模型 A]
    B --> B2[选择模型 B]
    B --> B3[可添加更多模型]
    B --> C[点击"对比"按钮]
    
    C --> LOAD[加载各模型数据]
    LOAD --> LOAD_DIMS[加载各维度数据]
    
    LOAD_DIMS --> DIM1[响应质量评分]
    LOAD_DIMS --> DIM2[平均延迟]
    LOAD_DIMS --> DIM3[Token 成本]
    LOAD_DIMS --> DIM4[上下文长度]
    LOAD_DIMS --> DIM5[多模态能力]
    LOAD_DIMS --> DIM6[中文理解]
    LOAD_DIMS --> DIM7[代码生成]
    
    DIM1 --> SCORE[计算综合评分]
    DIM2 --> SCORE
    DIM3 --> SCORE
    DIM4 --> SCORE
    DIM5 --> SCORE
    DIM6 --> SCORE
    DIM7 --> SCORE
    
    SCORE --> SCORE_CALC[加权求和]
    SCORE_CALC --> SHOW[展示对比结果]
    
    SHOW --> RESULT1[多维度对比表格]
    SHOW --> RESULT2[综合评分排名]
    SHOW --> RESULT3[成本 vs 质量分布图]
    SHOW --> RESULT4[推荐建议]
    
    RESULT4 --> RECOMMEND[根据场景推荐]
    RECOMMEND --> R1[日常对话/客服 → DeepSeek-V3]
    RECOMMEND --> R2[复杂推理/代码 → GPT-4o]
    RECOMMEND --> R3[多模态任务 → GPT-4o]
    RECOMMEND --> R4[高并发低成本 → DeepSeek-V3]
    
    R4 --> END([结束])
```

## 对比维度

| 维度 | 数据来源 | 权重 | 说明 |
|------|----------|------|------|
| 响应质量评分 | 人工评分/历史评估 | 30% | 回答准确性和相关性 |
| 平均延迟 | 网关监控数据 | 15% | 模型响应时间 |
| Token 成本 | Token 统计 | 25% | 单位 Token 费用 |
| 上下文长度 | 模型规格 | 10% | 支持的最大上下文 |
| 多模态能力 | 模型规格 | 5% | 是否支持图像/音频 |
| 中文理解 | 人工评分 | 10% | 中文理解和生成质量 |
| 代码生成 | 人工评分 | 5% | 代码生成质量 |
