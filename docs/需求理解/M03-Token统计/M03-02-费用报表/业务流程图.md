# M03-02 费用报表 — 业务流程图

## 流程概述

基于 Token 消耗数据和各模型单价计算费用，生成多维度费用报表，支持导出为 CSV/Excel。

## 业务流程图

```mermaid
flowchart TD
    START([开始]) --> LOAD[加载 Token 用量数据]
    LOAD --> PRICE[读取各模型单价配置]
    PRICE --> CALC[计算费用]
    CALC --> FORMULA[费用 = Σ(模型Token消耗 × 模型单价)]
    FORMULA --> AGG_BY[多维度聚合]
    
    AGG_BY --> AGG_MODEL[按模型聚合<br/>展示各模型费用占比]
    AGG_BY --> AGG_APP[按应用聚合<br/>展示各应用费用占比]
    AGG_BY --> AGG_USER[按用户聚合<br/>展示各用户费用占比]
    
    AGG_MODEL --> DASHBOARD[费用看板]
    AGG_APP --> DASHBOARD
    AGG_USER --> DASHBOARD
    
    DASHBOARD --> D1[今日费用]
    DASHBOARD --> D2[本月累计费用]
    DASHBOARD --> D3[费用趋势]
    DASHBOARD --> D4[费用占比饼图]
    
    DASHBOARD --> EXPORT{选择导出}
    EXPORT -->|CSV| EXPORT_CSV[导出 CSV 格式]
    EXPORT -->|Excel| EXPORT_XLSX[导出 Excel 格式]
    EXPORT_CSV --> END([结束])
    EXPORT_XLSX --> END
```

## 费用计算模型

| 模型 | 输入单价 (¥/1K Token) | 输出单价 (¥/1K Token) |
|------|----------------------|----------------------|
| DeepSeek-V3 | 0.001 | 0.002 |
