# M03 Token 统计模块

## 模块概述

Token 统计模块负责实时监控和统计分析所有 API 调用的 Token 消耗和费用，提供多维度下钻查看能力，并支持用量预警。

## 子模块清单

| 子模块编号 | 子模块名称 | 优先级 | 功能点 |
|------------|-----------|--------|--------|
| M03-01 | 用量统计 | Must | F-008 Token 用量实时统计 |
| M03-02 | 费用报表 | Must | F-009 多维度费用报表 |
| M03-03 | 用量预警 | Should | F-010 用量预警规则 |

## 功能点列表

| 功能编号 | 功能名称 | 优先级 | 复杂度 |
|----------|----------|--------|--------|
| F-008 | Token 用量实时统计 | Must | M |
| F-008.1 | 按模型统计 | Must | S |
| F-008.2 | 按应用统计 | Must | S |
| F-008.3 | 按用户统计 | Should | S |
| F-009 | 多维度费用报表 | Must | M |
| F-010 | 用量预警规则 | Should | M |

## 角色与权限

| 角色 | 权限 |
|------|------|
| 平台管理员 | 全部查看、配置预警规则 |
| 应用开发者 | 查看自己应用的用量和费用 |
| 业务管理者 | 查看全部用量和费用报表 |
