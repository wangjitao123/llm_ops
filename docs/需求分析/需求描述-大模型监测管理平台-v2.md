# 大模型监测管理平台 - 需求描述 v2

## 项目概述
构建一个统一的**大模型监测管理平台**，为企业内部提供大模型的全生命周期管理能力，包括模型管理、API Key分发与鉴权、Token用量统计、统一网关路由、模型微调等核心功能。

## 核心功能需求

### 1. 大模型管理
- 支持接入多种大模型（如 DeepSeek、GPT、文心一言、通义千问等）
- 模型的注册、配置、启停管理
- 模型版本管理
- 模型运行状态监控

### 2. Key 分发与管理
- API Key 的生成、分发、回收
- 支持多用户/多应用维度
- Key 的权限控制（可调用哪些模型、速率限制）
- Key 的生命周期管理（有效期、自动过期）

### 3. Token 统计
- 实时/历史 Token 用量统计
- 按用户、应用、模型维度统计
- 费用核算与账单生成
- 用量预警与阈值告警

### 4. 统一网关
- 统一 API 入口，路由到不同后端模型服务
- 请求鉴权（校验 API Key）
- 负载均衡与限流
- 请求日志与审计
- 协议转换（适配不同模型厂商的 API 格式）

### 5. 模型微调
- 微调任务管理（创建、监控、管理）
- 训练数据集管理（上传、标注、版本管理）
- 微调参数配置
- 微调结果评估与对比
- 微调后模型的部署

### 6. 模型对比评估（新增）
- 多模型响应质量对比
- 成本（Token 消耗、费用）对比
- 响应速度（延迟）对比
- 对比结果可视化展示

### 7. 系统管理
- 对接公司 SSO 统一认证（无需独立用户管理页面）
- 角色权限管理（RBAC）
- 操作日志
- 系统配置（钉钉通知推送 → 个人或群聊）

## 用户体验目标
- 提供可视化 Web 管理界面，操作简便
- 实时数据展示与监控大屏
- 支持多维度数据导出（报表）
- 响应式设计，支持主流浏览器

## 技术方向
- 后端：Java / Python（微服务架构）
- 前端：Vue3 / React
- 数据库：MySQL + Redis
- 消息队列：用于异步任务处理
