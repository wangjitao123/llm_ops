# 待澄清问题 - 模型量化模块

## Q01：量化后模型的部署方式

量化后的模型（保存在 `/models/` 共享卷中）在平台如何被使用？目前平台模型都是 API 代理模式（配置 `api_base_url` + `api_key`），量化后的模型文件是 HuggingFace 格式，不能直接通过 API 调用。

- **建议方案**：量化完成后注册的模型标记为 `provider=quantized`，API 地址填 `file://` 路径。后续如需推理，需要部署推理引擎（如 vLLM / TGI），部署后的服务地址手动填入。

## Q02：GPU Worker 的 GPU 分配

8 张 L20（48GB/张），量化 Worker 的 concurrency=1 一次只占 1 张卡。是否需要支持选择指定 GPU？

- **当前方案**：简单，默认使用 `CUDA_VISIBLE_DEVICES=0` 或让 PyTorch 自动选择。
- **可选增强**：创建任务时可选 GPU 编号（如 GPU:0~7），适合多任务并行。
- **请确认**：现在用单卡串行是否需要改？

## Q03：校准自定义数据集格式

自定义校准文本默认按行分割，每行一条样本。是否需要支持其他格式（如 JSONL，每条包含 `{"text":"..."}`）？

- **当前方案**：支持 .txt（纯文本行）和 .jsonl 两种格式自动识别
- **请确认**：用户上传的校准文件最多允许多大（如 10MB）？

## Q04：模型文件下载方式

量化完成的模型权重文件通常较大（4bit 7B 模型约 3-4GB），下载方式如何？

- **方案 A**：在后端打包为 tar.gz，通过 HTTP 流式下载
- **方案 B**：提供 rsync/scp 命令提示，让用户在服务器上操作
- **请确认**：优先实现哪个方案？
