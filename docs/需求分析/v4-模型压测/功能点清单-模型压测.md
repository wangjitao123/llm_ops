## ⚠️ 与已有「模型对比评估」的边界
| | 模型对比评估（已有 F-017） | 模型压测（本模块） |
|---|---|---|
| 对比什么 | **质量**：回答质量评分、成本 | **性能**：TTFT、吞吐、成功率 |
| 怎么比 | 同一问题问多个模型 | 高并发打同一个模型 |
| 数据来源 | 调用结果打分 | 压测指标 |
| 结论 | 选哪个模型更好 | 这个模型能扛多少 |
