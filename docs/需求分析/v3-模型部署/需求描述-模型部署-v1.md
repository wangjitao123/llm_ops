# 需求描述 - 模型部署功能 v1

## 项目名称
大模型监测管理平台（AI网关）

## 需求描述
在现有平台基础上增加**模型部署**功能，支持将量化后的模型（来自模型量化模块）或HuggingFace开源模型一键部署为本地推理端点，实现"量化→部署→使用"的完整闭环。

## 核心价值
1. **消除断点**：当前量化后的模型只能保存到共享卷，无法直接对外提供推理服务，需要手动装vLLM等工具
2. **降低门槛**：运维人员无需了解vLLM/TGI等推理引擎的部署细节，在UI上点几下即可完成部署
3. **统一管理**：已部署的模型自动注册到现有模型管理模块，通过统一网关路由调用

## 核心场景

### 场景A：从量化结果部署
用户在模型量化模块完成量化后，点击"部署"按钮 → 系统将该量化模型部署为一个推理端点 → 部署完成后自动注册到模型管理 → 用户可在网关中调用

### 场景B：从HuggingFace直接部署
用户在部署界面输入HuggingFace模型ID（如 `Qwen/Qwen2.5-7B-Instruct`），选择推理引擎和资源配置 → 一键部署

### 场景C：已部署模型管理
查看所有已部署模型的列表（状态、引擎占用、并发数）、启停操作、监控指标

## 技术约束
- 服务器 GPU：8×NVIDIA L20（48GB）
- 推理引擎：vLLM（优先，支持GPTQ/AWQ量化模型）和 TGI 作为备选
- 共享卷：已挂载 `quantized_models:/models` 量化模型存储卷
- 部署方式：Docker容器部署，每个推理实例一个容器
- 模型来源：量化模型的保存路径可对接，HuggingFace ID可直接下载

## 期望产出
- 模型部署的Web管理界面
- 一键部署的API/后台任务机制
- 推理端点生命周期管理（启动/停止/监控）
- 与现有模型管理模块和网关的自动集成
