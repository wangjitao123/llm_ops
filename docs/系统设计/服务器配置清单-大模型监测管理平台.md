## 硬件配置说明

| 配置项 | 建议 |
|--------|------|
| CPU | Intel Xeon 或 AMD EPYC，主频 2.5GHz+ |
| 内存 | DDR4 或 DDR5 ECC |
| 磁盘 | NVMe SSD（MySQL 数据盘推荐 4K 随机读写 > 50K IOPS） |
| 网络 | 生产环境建议 1Gbps 双网卡绑定 |
| RAID | 数据盘建议 RAID 10 |
| 电源 | 双冗余电源 |
