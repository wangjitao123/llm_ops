## 4. 网关选型：Higress AI Gateway

### 4.1 Higress 简介

**Higress** 是阿里开源的一站式云原生 AI 网关，基于 Envoy 内核构建，已通过 Apache 2.0 协议开源。它提供：

| 能力 | 说明 | 本平台用途 |
|------|------|-----------|
| **AI 路由** | 支持基于模型名、请求路径的路由分发 | 路由到不同模型厂商 |
| **Key 鉴权** | 内置 API Key 认证机制 | 替代自研鉴权模块 |
| **速率限制** | 支持全局/单 Key 限流 | 流量控制 |
| **协议转换** | 自动转换 OpenAI 格式 ↔ 各厂商格式 | 统一 API 协议 |
| **请求日志** | 可观测性，支持 Prometheus + 自定义日志 | 支撑 Token 统计 |
| **模型管理** | 服务发现、健康检查、灰度发布 | 模型启停、版本管理 |
| **Wasm 扩展** | 支持 Wasm 插件扩展能力 | 自定义业务逻辑 |

### 4.2 Higress vs 其他网关方案

| 对比项 | **Higress** ✅ | 自研 Spring Cloud Gateway | Kong AI Gateway | Envoy AI Gateway |
|--------|---------------|--------------------------|-----------------|------------------|
| AI 场景原生 | ✅ 原生支持 | ❌ 需自行开发 | ✅ 插件支持 | ✅ 原生支持 |
| 协议转换 | ✅ 内置 | ❌ 需开发 | ⚠️ 需插件 | ⚠️ 需扩展 |
| 开源协议 | Apache 2.0 | 自研 | Apache 2.0 | Apache 2.0 |
| 部署方式 | 容器化 / K8s | 容器化 | 容器化 / K8s | 容器化 / K8s |
| 运维复杂度 | 低 | 高 | 中 | 中 |
| 社区活跃度 | ⭐⭐⭐⭐ | — | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 中文文档 | ✅ 完善 | — | ⚠️ 英文为主 | ⚠️ 英文为主 |
| **结论** | **✅ 推荐** | 不推荐 | 可选 | 可选 |

### 4.4 Higress 关键配置示例

```yaml
# Higress AI Gateway 配置示例
apiVersion: extensions.higress.io/v1alpha1
kind: AiRoute
metadata:
  name: chat-route
spec:
  # AI 路由规则
  aiModels:
    - model: deepseek-v3
      targetProvider:
        type: custom
        host: "api.deepseek.com"
        apiKey: "${DEEPSEEK_API_KEY}"
    - model: gpt-4o
      targetProvider:
        type: openai
        apiKey: "${OPENAI_API_KEY}"
  # 路由策略
  rule:
    - match:
        path: /v1/chat/completions
      route:
        - model: deepseek-v3
          weight: 60
        - model: gpt-4o
          weight: 40
  # 鉴权配置
  auth:
    apiKey:
      source: HEADER
      keyName: Authorization
      prefix: "Bearer "
      # 指向后端的 Key 管理服务进行校验
      verifyUrl: http://api-server:8000/api/v1/gateway/verify-key
  # 速率限制
  rateLimit:
    global:
      qps: 5000
    perConsumer:
      qps: 100
```

## 6. 数据层选型

| 对比项 | MySQL 8.0 | PostgreSQL 16 |
|--------|-----------|---------------|
| 事务支持 | ✅ | ✅ |

| 用途 | Python 库 | 说明 |
|------|----------|------|
| 业务缓存 | `redis-py` + `aioredis` | 异步驱动 |

| 会话管理 | `redis-py` | JWT 黑名单 |
| 消息队列 | `redis-py`（兼容 Celery） | 可选，建议 RabbitMQ |

### 6.3 消息队列：RabbitMQ

## 10. 架构优势总结

### 对比原 Java + 自研网关方案

| 维度 | Java + 自研网关 | Python + Higress（现方案） |
|------|----------------|--------------------------|
| 网关开发工作量 | 高（需自研鉴权/路由/限流/协议转换） | **低**（Higress 开箱即用） |
| AI 生态衔接 | 中（需对接各厂商 SDK） | **高**（Python 原生生态） |
| 微调模块 | 低（Java 不适合 ML 场景） | **高**（PyTorch/Transformers 直接用） |
| 开发效率 | 中 | **高**（FastAPI 代码量少 40%） |
| 网关性能 | 5,000 QPS | **10,000+ QPS**（Higress 基于 Envoy） |
| 运维复杂 | 高 | **中**（Higress 降低网关运维） |
| 团队招聘 | 中 | **高**（Python 人才更易获取） |
