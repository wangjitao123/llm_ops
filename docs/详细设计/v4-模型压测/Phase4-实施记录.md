## 页面结构

### 1. 列表页
- **统计卡片**：累计任务 / 成功完成 / 运行中 / 最近 TTFT(P99)
- **筛选**：状态、模型、任务名搜索
- **表格**：任务名(+时间) / 目标模型(含「经网关」标签) / 模式 / 压力参数 / 状态(含进度条+RPS) / TTFT(P99) / 输出吞吐 / 操作
- **操作**：详情 / 中止(排队或运行中) / 报告下载(已完成) / 重跑 / 删除
- **自动刷新**：检测到 `pending`/`running` 任务时每 3 秒轮询；全部结束后自动停

### 2. 新建压测（4 区）
| 区 | 内容 |
|----|------|
| 1 目标模型 | 下拉（后端已过滤为 `local-*` 自建模型）+ 任务名 + **打法选择**（直连 / 经网关） |
| 2 压测模式 | 闭环并发 / 开环限速 / SLA 调压 / 多轮对话，切换时动态显示参数 |
| 3 输入构造 | 数据集类型 + 输入/输出长度（random 时必填） |
| 4 高级设置 | stream / temperature / 请求超时 / tokenizer |

快速模板 4 套：冒烟 50并发 / 标准基准 200并发 / SLA 找拐点 / 极限 500并发。

### 3. 结果详情
- 配置回显（模式 + 压力参数 + 数据集 + 耗时）
- 4 个指标卡：TTFT 均值(含 P99) / TPOT / 输出吞吐(含 req/s) / 成功率(按值着色)
- **延迟分位条**：P50/P90/P95/P99/Max，宽度按相对比例
- 失败原因分布表（来自 EvalScope 结果库）
- 终端风格运行日志

### 4. 历史对比
- 多选 2-4 个**已完成**任务
- 参数一致性提示：`strictly_comparable=true` 显示绿色「可严格对比」，否则黄色并列出差异字段
- 对比表：9 个指标 × N 个任务，每列显示相对第一个任务的变化百分比（涨红跌绿）

## 踩过的坑（提前规避）

| 坑 | 规避 |
|----|------|
| `v-model` 绑可选链 → esbuild "Invalid assignment target" | 全部改用确定存在的对象路径（如 `createForm.model_id`），不用 `?.` |
| 隐式 any 报错（TS7006） | 所有 `filter/map/find` 回调显式标注类型 |
| `PerfLogItem` 从错误的模块导入 | 定义在 `api/perfApi.ts`，从那里 import |
| 模板编译错误本地测不出来 | 用 `npm run verify`（`vue-tsc` + `check-templates.cjs`）双检 |
