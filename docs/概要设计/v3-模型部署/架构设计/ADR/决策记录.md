# ADR 决策记录

## ADR-001: 推理引擎选择
- **决策**: 默认使用 vLLM，TGI/SGLang 二期
- **原因**: GPTQ/AWQ 兼容性最好，社区最活跃
- **ADR文件**: `架构设计文档-模型部署.md` → ADR-001

## ADR-002: 健康检查方案
- **决策**: Celery Beat 定时任务
- **原因**: 与现有架构一致
- **ADR文件**: `架构设计文档-模型部署.md` → ADR-002

## ADR-003: conda/Docker 生命周期
- **决策**: 平台不管理外部进程生命周期
- **原因**: 用户已有独立管理体系，过度耦合风险高
- **ADR文件**: `架构设计文档-模型部署.md` → ADR-003

## ADR-004: 使用 Docker 容器管理新建部署
- **决策**: 每个部署独立 Docker 容器
- **原因**: 隔离性、资源明确、docker-py 成熟
- **ADR文件**: `架构设计文档-模型部署.md` → ADR-004
