# 数据库设计文档 — 模型部署模块

## 1. 部署配置表 (deployment)

核心表，记录每个部署的所有配置信息。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| name | VARCHAR(128) | NOT NULL UNIQUE | 部署名称 |
| deploy_type | VARCHAR(16) | NOT NULL DEFAULT 'managed' | 运行方式: managed/conda/docker/other |
| status | VARCHAR(16) | NOT NULL DEFAULT 'deploying' | 状态: deploying/running/stopped/failed/deleted |
| base_model_id | INT | FK → model.id | 基座模型ID（可选） |
| hf_model_id | VARCHAR(256) | NULL | HuggingFace 模型 ID |
| endpoint_url | VARCHAR(512) | NOT NULL | 端点 URL |
| engine | VARCHAR(16) | NULL | 推理引擎: vllm/tgi/sglang |
| gpu_ids | INTEGER[] | NULL | GPU 编号列表 |
| gpu_count | INT | DEFAULT 1 | GPU 数量 |
| gpu_memory_gb | DECIMAL(6,2) | NULL | 显存占用(GB) |
| max_concurrency | INT | DEFAULT 32 | 最大并发数 |
| max_input_tokens | INT | DEFAULT 4096 | 最大输入 Token |
| system_prompt | TEXT | NULL | System Prompt 模板 |
| temperature | DECIMAL(3,2) | DEFAULT 0.70 | 采样温度 |
| top_p | DECIMAL(3,2) | DEFAULT 0.90 | Top P 采样 |
| max_tokens | INT | DEFAULT 4096 | 最大输出 Token |
| frequency_penalty | DECIMAL(3,2) | DEFAULT 0.00 | 频率惩罚 |
| tools_json | JSONB | NULL | Tool Call 定义列表 |
| web_search_enabled | BOOLEAN | DEFAULT FALSE | 启用 Web Search |
| web_search_config | JSONB | NULL | 搜索配置 |
| env_vars | JSONB | NULL | 环境变量 |
| auto_register | BOOLEAN | DEFAULT TRUE | 自动注册到模型管理 |
| health_check_enabled | BOOLEAN | DEFAULT TRUE | 启用健康检查 |
| error_message | TEXT | NULL | 错误信息 |
| created_by | VARCHAR(64) | NOT NULL | 创建人 |
| created_at | TIMESTAMP | NOT NULL DEFAULT NOW() | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL DEFAULT NOW() | 更新时间 |

**索引**:
| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| idx_deployment_name | name | UNIQUE | 名称唯一 |
| idx_deployment_status | status | BTREE | 按状态筛选 |
| idx_deployment_deploy_type | deploy_type | BTREE | 按运行方式筛选 |
| idx_deployment_base_model | base_model_id | BTREE | 关联模型查询 |
| idx_deployment_created_at | created_at | BTREE | 按时间排序 |

## 2. 健康检查日志表 (deployment_health_log)

记录每次健康检查的结果，用于计算健康率和诊断。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| deployment_id | BIGINT | NOT NULL FK → deployment.id | 关联部署 |
| status_code | INT | NULL | HTTP 状态码 |
| latency_ms | INT | NULL | 延迟(ms) |
| is_healthy | BOOLEAN | NOT NULL | 是否健康 |
| error_message | TEXT | NULL | 错误信息 |
| checked_at | TIMESTAMP | NOT NULL DEFAULT NOW() | 检查时间 |

**索引**:
| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| idx_health_deploy_time | (deployment_id, checked_at) | BTREE | 按部署和时间查询 |
| idx_health_checked_at | checked_at | BTREE | 清理旧数据 |

**分区建议**: 按月分区，保留 3 个月健康日志

## 3. 性能指标聚合表 (deployment_metrics)

每 5 分钟聚合的性能指标。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| deployment_id | BIGINT | NOT NULL FK → deployment.id | 关联部署 |
| qps | DECIMAL(8,2) | NULL | 平均 QPS |
| p50_latency_ms | DECIMAL(8,2) | NULL | P50 延迟 |
| p99_latency_ms | DECIMAL(8,2) | NULL | P99 延迟 |
| avg_latency_ms | DECIMAL(8,2) | NULL | 平均延迟 |
| error_rate | DECIMAL(5,4) | NULL | 错误率 |
| total_requests | INT | DEFAULT 0 | 总请求数 |
| window_start | TIMESTAMP | NOT NULL | 窗口开始 |
| window_end | TIMESTAMP | NOT NULL | 窗口结束 |

**索引**:
| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| idx_metrics_deploy_window | (deployment_id, window_start) | BTREE | 查询趋势数据 |

## 4. 部署日志表 (deployment_log)

运行日志，用于详情页展示。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 主键 |
| deployment_id | BIGINT | NOT NULL FK → deployment.id | 关联部署 |
| level | VARCHAR(8) | NOT NULL DEFAULT 'info' | 级别: info/warn/error/ok |
| message | TEXT | NOT NULL | 日志内容 |
| created_at | TIMESTAMP | NOT NULL DEFAULT NOW() | 日志时间 |

**索引**:
| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| idx_log_deploy_time | (deployment_id, created_at) | BTREE | 按部署和时间查询 |
