# 数据字典 — 模型部署模块

## 枚举值定义

### deploy_type (运行方式)
| 值 | 标签 | 说明 |
|----|------|------|
| managed | 平台管理 | 平台自动创建的 Docker 容器，有完整生命周期管理 |
| conda | Conda 环境 | 用户在 conda 环境中手动启动的模型进程 |
| docker | Docker 容器 | 用户手动管理的 Docker 容器 |
| other | 其他 | 其他运行方式 |

### status (部署状态)
| 值 | 标签 | 说明 |
|----|------|------|
| deploying | 部署中 | 新建部署正在启动（仅平台管理类型） |
| running | 运行中 | 健康检查通过，正常运行 |
| stopped | 已停止 | 用户手动停止（仅平台管理类型） |
| failed | 失败 | 部署失败 / 健康检查连续异常 |
| deleted | 已删除 | 逻辑删除 |

### engine (推理引擎)
| 值 | 标签 | 说明 |
|----|------|------|
| vllm | vLLM | 推荐引擎 |
| tgi | TGI | HuggingFace 官方（二期） |
| sglang | SGLang | 新兴引擎（二期） |

### level (日志级别)
| 值 | 标签 | 说明 |
|----|------|------|
| info | INFO | 普通信息 |
| warn | WARN | 警告 |
| error | ERROR | 错误 |
| ok | SUCCESS | 成功/完成 |

## 健康检查指标
| 指标 | 正常范围 | 说明 |
|------|---------|------|
| 状态码 | 200 | HTTP 响应码 |
| 延迟 | < 5000ms | 超时 5s 视为失败 |
| 健康率 | ≥ 99.0% | 连续 3 次失败标记异常 |
