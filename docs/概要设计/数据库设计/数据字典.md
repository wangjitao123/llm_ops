# 数据字典 — 大模型监测管理平台

## 1. 枚举值定义

### 1.1 模型提供商枚举

| 值 | 说明 | 对应厂商 |
|----|------|----------|
| deepseek | 深度求索 | DeepSeek |
| openai | OpenAI | GPT-4o / GPT-4o-mini |
| aliyun | 阿里云 | 通义千问系列 |
| baidu | 百度 | 文心一言系列 |
| anthropic | Anthropic | Claude 系列 |
| google | Google | Gemini 系列 |

### 1.2 模型状态枚举

| 值 | 说明 | 含义 |
|----|------|------|
| online | 在线 | 正常运行，可路由 |
| offline | 离线 | 连续 3 次心跳失败，网关停止路由 |
| high_latency | 高延迟 | 响应时间持续超过 500ms |
| pending | 待配置 | 刚创建，未完成初始化配置 |

### 1.3 心跳状态枚举

| 值 | 说明 | 含义 |
|----|------|------|
| online | 在线 | 响应正常，延迟在阈值内 |
| offline | 离线 | 请求超时或连接失败 |
| high_latency | 高延迟 | 响应时间 > 500ms |

### 1.4 API Key 状态枚举

| 值 | 说明 | 含义 |
|----|------|------|
| active | 启用 | 正常使用，可鉴权通过 |
| disabled | 禁用 | 管理员手动禁用，鉴权不通过 |
| expired | 过期 | 超过过期时间，自动禁用 |
| revoked | 回收 | 已删除，不可恢复 |

### 1.5 路由匹配类型枚举

| 值 | 说明 | 示例 |
|----|------|------|
| exact | 精确匹配 | /v1/chat/completions |
| prefix | 前缀匹配 | /v1/chat/* |
| regex | 正则匹配 | /v1/.*/completions |

### 1.6 路由策略枚举

| 值 | 说明 | 算法 |
|----|------|------|
| weighted | 加权轮询 | 按权重比例分发请求 |
| active_standby | 主备切换 | 主模型不可用时切到备用模型 |
| single | 单点 | 固定路由到指定模型 |

### 1.7 微调任务状态枚举

| 值 | 说明 | 含义 |
|----|------|------|
| pending | 待运行 | 刚创建，等待资源检查 |
| queued | 排队中 | 资源检查通过，等待 GPU 分配 |
| running | 运行中 | 正在训练 |
| paused | 暂停 | 用户手动暂停 |
| completed | 已完成 | 训练正常结束 |
| failed | 失败 | 训练异常终止 |
| cancelled | 已取消 | 用户手动取消 |
| deployed | 已部署 | 微调模型已发布为版本 |

### 1.8 数据集格式枚举

| 值 | 说明 | 适用场景 |
|----|------|----------|
| jsonl | JSON Lines | 最常用格式，每行一个 JSON 对象 |
| csv | CSV | 简单表格数据 |
| json | JSON 数组 | 小规模数据 |
| parquet | Parquet | 大规模数据，压缩率高 |

### 1.9 数据集标注状态枚举

| 值 | 说明 | 含义 |
|----|------|------|
| pending | 待标注 | 未开始标注 |
| labeling | 标注中 | 正在标注 |
| labeled | 已标注 | 标注完成，待审核 |
| reviewing | 审核中 | 正在审核 |
| reviewed | 已审核 | 审核通过 |

### 1.10 预警指标类型枚举

| 值 | 说明 | 统计周期 |
|----|------|----------|
| daily_token | 日 Token 用量 | 按天统计 |
| monthly_token | 月 Token 用量 | 按月统计 |
| daily_cost | 日费用 | 按天统计 |
| monthly_cost | 月费用 | 按月统计 |

### 1.11 预警级别枚举

| 值 | 说明 | 响应要求 |
|----|------|----------|
| warn | 警告 | 15 分钟内响应 |
| critical | 严重 | 立即响应 |

### 1.12 操作审计类型枚举

| 值 | 说明 | 示例 |
|----|------|------|
| model_create | 创建模型 | 接入新模型 |
| model_update | 更新模型 | 修改模型配置 |
| model_delete | 删除模型 | 移除模型 |
| model_start | 启用模型 | 模型上线 |
| model_stop | 停用模型 | 模型下线 |
| key_create | 创建 Key | 生成新 API Key |
| key_update | 更新 Key | 修改 Key 配置 |
| key_delete | 删除 Key | 回收 Key |
| key_disable | 禁用 Key | 手动禁用 |
| route_create | 创建路由 | 新增路由规则 |
| route_update | 更新路由 | 修改路由规则 |
| route_delete | 删除路由 | 删除路由规则 |
| finetune_create | 创建微调任务 | 提交微调任务 |
| finetune_cancel | 取消微调任务 | 取消任务 |
| alert_config | 配置预警规则 | 新增/修改预警规则 |
| sso_config | 配置 SSO | 修改 SSO 认证配置 |
| notification_config | 配置通知 | 修改通知渠道配置 |

### 1.13 审计结果枚举

| 值 | 说明 |
|----|------|
| success | 操作成功 |
| failure | 操作失败（如权限不足、参数错误） |

### 1.14 Token 统计维度类型枚举

| 值 | 说明 |
|----|------|
| model | 按模型维度统计 |
| application | 按应用维度统计 |

| user | 按用户维度统计 |

### 1.15 SSO 协议枚举

| 值 | 说明 | 适用场景 |

### 1.16 导出任务状态枚举

|----|------|------|
