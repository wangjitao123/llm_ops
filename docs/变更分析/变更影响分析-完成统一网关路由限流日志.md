# 变更影响分析报告：完成统一网关（平台内置路由分发 + 限流 + 日志关联）

- 项目：大模型监测管理平台
- 变更类型：feature（把 M04 统一网关从"配置面"做成"运行时真正执行"）
- 日期：2026-09-08
- 状态：待评审确认

---

## 1. 现状与缺口

M04 已有：路由规则 CRUD 前后端完整（路径匹配 exact/prefix/regex、策略 weighted/active_standby/single、
目标模型含 weight/priority、启停）、`rate_limit_config` 与 `app_key.qps_limit/rpm_limit/rpd_limit/token_quota`
字段、`api_request_log.route_rule_id` 列。

**缺口（代码实锤）**：
1. 运行时请求转发**不读路由规则**——`proxy.py` 按请求体 `model` 名直查 model 表转发；路由规则只入库不执行；
2. `sync_to_higress()` 是 TODO 占位（本次不做 Higress）；
3. **限流未执行**（无任何 QPS 校验）；
4. 请求日志 `route_rule_id` 从不填写。

## 2. 目标（经用户确认的范围）

1. **路由分发**：请求命中启用路由时，按策略在目标模型组内选一个后端转发；
2. **限流**：全局 QPS + 单 Key QPS（Redis 计数，跨 worker 准确）；
3. **日志**：`api_request_log.route_rule_id` 记录命中的路由 id；`model_id` 记录实际选中的目标模型；
4. **兼容**：路由未命中 → 完全维持现有"按 model 名直连"行为，不影响当前可用调用；
5. 不碰 Higress（同步按钮改为明确提示"未启用 Higress，路由由平台内置执行"）。

## 3. 执行契约（待确认）

**路由匹配**：路径命中 + 策略组选择：
- 请求进来先做 Key 鉴权（现状）；
- 在启用路由中按 `priority` 顺序找第一个**路径匹配**的路由（exact=全等 / prefix=前缀 / regex=正则）；
- 在该路由的目标模型中，过滤出 **`model.name == 请求体 model 名` 且 `status == online`** 的目标集
  （即：一个路由 = 同一逻辑模型的多实例后端组，用于负载均衡/主备容灾）；
- 目标集非空 → 按路由策略选一个实际后端：
  - `single`：唯一目标；
  - `weighted`：按 `weight` 加权轮询（进程内计数器，多 worker 近似）；
  - `active_standby`：按 `priority`（0=主）取在线目标；主目标**连接级失败**（超时/网络错）时按序切下一个备，只重试一次（生成完成后的 5xx 不重试，避免重复扣费）；
- 无路由命中 / 命中但目标集为空 → 回退现有"按 model 名直连"（保持可用）；
- Key 模型权限校验沿用（有绑定则目标模型必须在允许列表，否则 403）；
- 全部目标不可用 → 503（与 M04 文档一致）。

**限流**（Redis 固定窗口，按当前秒计数）：
- key 前缀：`gw:rl:g:<epoch秒>`（全局）、`gw:rl:k:<key_id>:<epoch秒>`（单 Key）；INCR + EXPIRE 2s；
- 超限 → 429 + `Retry-After: 1`；先全局后单 Key；
- 限额来源：`rate_limit_config`（config_key='default' 行，缺行则用列默认值：global_qps=5000、default_key_qps=100）→ 单 Key 若有 `app_key.qps_limit` 则优先用其值；
- 本期只做 QPS；`rpm/rpd/token_quota` 字段保留、暂不执行（写入文档留档，后续可加）；
- 限流计数在 Key 鉴权通过后、真正转发前进行；鉴权失败不计。

**日志**：`record_request()` 增加 `route_rule_id` 透传（全部错误/成功/流式路径都带上命中值）。

## 5. 风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| 影响现有可用链路 | 改动的是正在工作的 /v1/chat/completions 热路径 | 严格"未命中即回退"；错误分支全部保留原行为；全量回归 |
| 加权轮询多 worker 不均 | 进程内计数器近似 | 可接受（文档注明）；如需精确可后续改 Redis 原子轮询 |
| 主备重试可能双执行 | 只对**连接级失败**重试，生成完成/5xx 不重试 | 文档写明边界 |
| Redis 不可用 | 限流失效或误伤 | api 启动已强依赖 redis（lifespan ping）；限流失败时按放行并告警日志，避免网关不可用 |
| 同 model 名多实例 | 与现有"唯一名直连"并存 | 直连解析增加 order_by/limit 容错，避免重复名时 500 |
